# Security Policy

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Report suspected vulnerabilities by emailing `dev@amorelliaoyan.com` with:

- A clear description of the issue.
- Steps to reproduce, if available.
- Impact and affected versions, if known.
- Any relevant logs, proof of concept, or mitigation ideas.

You should receive an initial response within 7 days. Security reports are reviewed privately, and confirmed vulnerabilities will be fixed and disclosed responsibly.

## Supported Versions

This project is early-stage. Security fixes target the latest released version unless otherwise stated in a release note.

## Secrets and Credentials

Do not include tokens, API keys, private keys, passwords, or other secrets in issues, pull requests, discussions, logs, screenshots, or test fixtures.
